## Chained Beastsのソロランはなぜ勝手が違うのか

Chained Beastsのソロランは、友人に向かって叫ぶために作られたゲームを、静かで残酷な自己規律の試練へと変える。コロシアムは責める相手がいないことなど気にしない。観客は依然として血を求め、ボスは依然として有利に盤面を組み、傷はすべて次の試合までついてくる。一人でアリーナを走り抜けることを学ぶ意味は大きい。ソロこそ、ゲームの本当のシステム——鎖の張力、観客の好感度、負傷の累積、環境キル——が牙をむく場所だからだ。

これがChained Beastsのソロランの魅力だ。Featherweight Gamesはこの剣闘士ローグライクを1〜4人用に作ったので、シングルプレイは後付けではなく正式にサポートされた道だが、リズムはまったく異なる。協力プレイでは会話で問題を解決する。一人では、二部屋先まで計画して解決する。本作は2026年10月15日にリリースされ、数百件のSteamレビューで「非常に好評」を維持しており、プレイヤーは戦闘の手触りとドタバタの混沌を一貫して称賛している。現在のビルド、デモ、パッチノートは[Chained Beasts公式Steamストアページ](https://store.steampowered.com/app/3569420/Chained_Beasts/)で確認できる。

| 要素 | 協力ラン（2〜4人） | ソロラン（1人） |
| --- | --- | --- |
| 鎖の張力 | 絶え間ない綱引き。一度の悪い動きがチームを引きずる | 自分の間合いだけを管理すればよい |
| 観客の好感度 | 注意が分散し、テンポを崩しやすい | 派手なキルがすべてメーターを伸ばす |
| 受けるダメージ | ヘイトを分担し、相棒が助け出せる | 安全網なし。一部屋の失敗でその日は終わる |
| ボス戦 | 連携したバーストと注意散らし | 消耗戦、カイト、ハザード頼み |
| 経済 | 購入を分担し、役割を特化 | すべてのコインで汎用の価値を買う必要がある |
| ミス許容度 | 中 | 低——ミスは日をまたいで積み重なる |

敵の数やボスの体力が剣闘士一人に対して具体的にどうスケールするかの公式な内訳は公開されていない。そのため上の表はデータマイニングされた数値ではなく、プレイヤー体験とローグライク全般の論理として受け取ってほしい。コミュニティ報告が一致しているのはテーマだ。ソロは安全網を取り除くのであって、見せ場を取り除くのではない。

## 相棒なしの立ち回りと鎖の規律

鎖は本作の象徴的な仕組みであり、協力プレイで鎖に殺されないための習慣は、そのままソロの剣闘士を生かす習慣になる。間合い、意図的な移動、衝動的にハザードを横切らないこと——すべて直接役立つ。アリーナに自分一人しかいなければ、それらの習慣が防御キットのすべてになる。

- **直線ではなく弧を描いて動く。** 集団へ真っ直ぐ突っ込むのは、ソロランが最初の週で終わる典型だ。円を描いて敵を固まらせ、それから踏み込む。
- **最大の脅威との間にハザードを一つ挟む。** トゲ壁や蛇穴は、自分がそこに立っていなければ無料のダメージ源になる。
- **環境キルで観客の好感度を貯める。** 壺で殴る、トゲへ押し込むといった行為は、削りダメージよりも観客ウケがよい。
- **戦利品を漁る前に部屋を片付ける。** 戦闘が半端な状態での欲張りは、ランを死なせる最もよくある原因だ。
- **投擲武器は一度きりの資源として扱う。** 二本目の武器を用意できているときだけ投げる。さもないと空振りすることになる。

プレイヤー体験からすると、観客はソロの剣闘士にとって協力プレイの相棒に最も近い存在だ。序盤に観客を味方につければ、アリーナは自分に逆らうのではなく、自分のために働き始める。

## Chained Beastsソロランのビルド優先度

誰も蘇生しに来ない以上、Chained Beastsのソロランでの購入判断はすべて一つの問いでふるいにかけるべきだ。それは「これは次の二試合を生き延びさせてくれるか？」。ダメージは簡単に見つかる。生存性はそうではない。

| 優先度 | 買う／覚えるもの | ソロで重要な理由 |
| --- | --- | --- |
| 1. 生存性 | ダメージ軽減、回避、回復 | 起こしてくれる相棒がいない |
| 2. 観客の好感度 | 観客を味方にするスキル | 観客が「二人目のプレイヤー」になる |
| 3. 武器の厚み | 常に信頼できる武器を二本 | 唯一の刃を投げるのは致命的 |
| 4. 機動力 | 移動スキル、位置調整ツール | カイトがボス戦略の柱になる |
| 5. 欲張り | 高リスクパーク、贅沢な強化 | ランが安定するまで先送りする |

さらに二つのルールが繰り返し報われる。第一に、キャラクターを着実に解放すること——異なる能力を持つ新しい剣闘士がいれば、同じ壁に頭をぶつけ続ける代わりに、苦手な相手へ別角度から挑める。第二に、序盤に全財産を一本の武器につぎ込まないこと。選択肢が三つある並のビルドは、選択肢が一つしかない優れたビルドに勝る。

## 負傷のトリアージ：恐ろしい怪我を一人で生き延びる

負傷システムこそ、ソロランの勝敗が本当に決まる場所だ。アリーナでの毎日は何か新しいものを残す——足を引きずる、片目を失う、自分にしか見えない幻覚——そしてポーションは一つの苦痛をより悪いものと引き換えにすることがある。協力プレイでは、負傷したプレイヤーは健康なプレイヤーの後ろに隠れられる。ソロでは、そのダメージを前提にビルドするしかない。

| 負傷／状態 | 実際の影響（プレイヤー体験） | ソロでの対応 |
| --- | --- | --- |
| 四肢の負傷／足を引きずる | 移動低下、回避が難しくなる | 遠距離手段とハザードに頼る。開けた地面を避ける |
| 失明／片目の喪失 | 視界が遮られ、読みが弱くなる | 狭い場所で戦い、敵を正面に保つ |
| 幻覚 | 幻の脅威、無駄なスイング | 速度を落とし、踏み込む前にターゲットを確認する |
| ポーションの副作用 | 新たなランダムの苦痛 | 現在の負傷がラン終了級のときだけ飲む |
| 手術 | ハイリスク・ハイリターン | まず金を貯める。ボス直前に賭けない |

コミュニティ報告は一点で一致している。すべてを治そうとする誘惑は罠だ。管理できる足の引きずりは生き延びられる。ダメージ出力を台無しにする新しい副作用は生き延びられない。どの負傷を抱えて進めるかを見極め、抱えられないものに資源を使うべきだ。

## ボス準備、アリーナのハザード、ランのペース配分

ボスはアリーナの英雄であり、あらゆる有利を備え、設計上こちらに不利な盤面を作ってくる。ソロの答えは彼らと打ち合い勝つことではない——位置取りで勝つことだ。環境を使い、逃げ道を開けておき、明確な硬直時間にだけダメージを叩き込む。

| ハザード | ソロでの最適な使い方 | リスク |
| --- | --- | --- |
| 壺 | 弾薬を使わずに遠距離ダメージ | 観客の好感度を稼ぐ機会を無駄にする |
| トゲ壁 | 突進してくるボスへの無料ダメージ | 回避中に自分が串刺しになる |
| 蛇穴 | エリア封鎖とカイトのレーン作り | コンボ中に突き落とされる |
| 投擲武器 | 低体力エリートの止め | 外すと武装解除されたまま立つことになる |

ペース配分は実行と同じくらい重要だ。Chained Beastsのソロランは小さな差が積み重なるマラソンであり、完走するプレイヤーは毎日を次の日の準備として扱う者たちだ。

| ランの段階 | 目標 | よくある失敗 |
| --- | --- | --- |
| 序盤 | 金を貯め、武器の手触りを試す | まだ使えないパークを買う |
| 中盤 | ビルドを安定させ、観客の好感度を稼ぐ | 負傷を放置して積み重ねる |
| ボス前 | 満体力、武器二本、逃げ道の把握 | 半分の体力で突入する |
| ボス戦 | カイトし、ハザードを使い、隙にバースト | 開けた場所で打ち合う |

## よくある質問

**Chained Beastsのソロランは本当に現実的ですか？**
はい。シングルプレイは明記された機能なので、ゲームはパーティーを必須にせず、一人でも遊べるように設計されています。協力プレイより遅く、守備的なペースを想定してください。カイトに時間をかけ、ハザードを使う時間が増え、開けた場所で打ち合う時間は減ります。Chained Beastsのソロランは攻撃性よりも忍耐に報います。

**ソロプレイにコントローラーは必要ですか？**
開発者はコントローラーを推奨しており、同一画面協力プレイには少なくとも一つのゲームパッドが必要です。ソロプレイでは、方向性のある戦闘と回避にはコントローラーのほうが一般的に快適ですが、投擲の狙いを好む多くのプレイヤーにとってキーボードとマウスも選択肢として残ります。

**Chained Beastsのソロランでは最初に何を買うべきですか？**
生存性です。ダメージ軽減、回避、回復は、ビルドの残りが意味を持つだけの長さ、ランを生かしてくれます。観客の好感度強化は二番目です。友好的な観客は、ソロの剣闘士にとって相棒に最も近い存在として機能するからです。

**ソロは協力プレイと比べてどれくらい難しいですか？**
コミュニティ報告では、ソロはより難しい道とされています。主な理由は蘇生がなく、ヘイトを分担する相手もいないことです。アリーナはいくつかの面で依然としてこちらに有利にスケールしますが、ミスの許容幅は狭くなります。最初の数回は偵察ランとして扱い、進めながらキャラクターを解放してください。
