## Chained Beastsの難易度レベルの構造

ティアは別々のキャンペーンではない。同じ3アクト構造の上に重ねられた修飾子であり、それぞれ次のティアが開放される前にクリアすることが前提とされている。この設計判断は重要だ。つまり進行はステータス依存ではなくスキル依存であり、残りHP4でかろうじて抜けたティアは、1週間後に余裕でクリアできるティアとは別物だということになる。

コミュニティの報告は一貫してこのラダーを「どんどん悲惨になっていく」と表現している。これはスタジオ自身の言葉でもあり、正直に言って的確だ。序盤のティアは鎖の物理挙動、観客、負傷システムを教えてくれる。後半のティアはそれらすべてを既に知っている前提で、いわば家賃を請求してくる。

| ティア帯 | 目的 | 典型的なランの感触 |
|---|---|---|
| 1〜2 | オンボーディング | 鎖、回避、ショップの優先順位を学べるだけの寛容さ |
| 3〜4 | 基礎の構築 | 雑な立ち回りは罰せられるが、基本的なビルドの相乗効果には報いる |
| 5〜6 | 本当の関門 | アフリクションの圧力と敵の密度が複合的に効き始める |
| 7〜8 | 最適化の領域 | 反射神経だけでなく、ボスへの計画が必要 |
| 9〜10 | マスタリー | すべてのミスに代償が伴い、1つの悪いアフリクションでランが終わる |

プレイヤー体験からの正直な注意点をひとつ。複数のレビュアーが、高ティアは主に敵が強く多くなることと、いくつかの追加メカニクスを加えるだけで、遭遇戦を作り直しているわけではないと指摘している。まったく新しいコンテンツを求めているなら、ティアはそれを与えてくれない — すでにあるものの、より鋭いバージョンを与えてくるのだ。

## ティア間で実際に変わるもの

ここが多くのガイドが曖昧になる部分なので、実用的なバージョンを示そう。ティアごとの正確な修飾子リストはスタジオから詳細には公開されていないが、chained beasts難易度レベル全体のパターンは一貫しており、観察可能だ。

| システム | スケーリングの仕方 | 戦闘での実感 |
|---|---|---|
| 敵の耐久力 | 体力が増え、危険な variants が登場 | 戦闘が長引き、鎖でのテザーが不利になる |
| 敵の密度 | アリーナ内の敵の数が増える | 群衆制御と範囲ダメージの価値が跳ね上がる |
| エリートの出現 | より強力な敵が頻繁に現れる | 単体特化ビルドが遅れを取り始める |
| アフリクションの圧力 | レベルアップと回復の選択がより危険に | より頻繁に、より悪いオッズで賭けることになる |
| ボスの挙動 | より容赦のないパターン | 暗記だけでは通用しなくなる |
| 鎖の摩擦 | 仲間同士の引っ張り合いがより厳しく | ポジショニングの規律が不可欠になる |

chained beasts難易度レベルを標準的なダメージスライダーとは別物にしているのは、アフリクションシステムだ。回復とレベルアップのどちらにも、ハンデを負わされる可能性がある — 色覚異常、武器の落下、四肢の喪失、あるいは永続的な炎上などだ。ティア1ではそれがコメディになる。ティア9ではランを決定づける判断になる。なぜなら、今のパワーと、その後のすべてに課される永続的な税のどちらかを選んでいるからだ。

だからこそ、ティアは周回よりも計画に報いる。真剣に時間を費やしたレビュアーは、このループを「ひどく弱体化される以上に強くなっていく」と表現しており、これがリスクとリワードの計算を最も簡潔にまとめた言葉だろう。

## ソロ vs. 協力プレイ：難易度レベルは異なる挙動をする

ここが新規プレイヤーをつまずかせる部分だ。同じティア番号でも、ソロとフルパーティでは同じ体験にはならない。Featherweight Gamesはこのギャップを公に認めており、難易度の急上昇をならすためのバランスパッチを示唆している — マルチプレイは少し難しくなり（最終ボスは例外）、シングルプレイは少し易しくなるという。

| 要素 | ソロ | 協力プレイ（2〜4人） |
|---|---|---|
| アイテム経済 | 見つけた強いアイテムはすべて自分のもの | 強力な拾い物は共有しなければならない |
| 鎖のメカニクス | テザーなし、引っ張り合いなし | 絶え間ない物理的干渉 — 笑えるが、やがて致命的 |
| 注意の分散 | 敵のヘイトはすべて自分に向く | ヘイトは分散するが、倒れた仲間は負債になる |
| スキルフロア | 1人あたりは高いが、連携コストは低い | 1人あたりは低いが、連携コストは非常に高い |
| 最も弱い環 | 自分だけ | パーティは経験の浅いメンバーとほぼ同じ強さ |
| 最適なビルドスタイル | 自己完結型、高サステイン | 役割分担：群衆制御、バースト、鎖専門の担当 |

プレイヤー体験もこれを裏付けている。あるコミュニティのコメント投稿者は、アイテムを共有する必要がなく鎖が危険でなくなるのでソロのほうが本当に簡単だと主張した — 一方で別の投稿者は、マルチプレイの難易度は最も弱い仲間に合わせてスケールするため、グループ次第で簡単から地獄まで大きく振れると指摘した。どちらも正しく、どちらも同じ設計上の緊張関係を語っている。

## Chained Beastsの難易度レベルを登るための実践的ヒント

中ティアから高ティアへのジャンプは、ほとんどのランが死ぬ場所であり、その理由はほぼ決して純粋なダメージ出力ではない。戦闘が終わった後の10秒間の判断なのだ。

- **回復は報酬ではなく取引として扱う。** 回復のたびにアフリクションの可能性がある。体力60%で次の戦闘が通常のウェーブなら、リスクを取って先に進もう。
- **受け入れる前にアフリクションを読む。** 走っているときに転ぶ足の指の欠損は対処可能だ。ティア8で腕を失うのは大抵そうではない。
- **望むアリーナではなく、今いるアリーナに合わせてビルドする。** 敵が密集するウェーブは単体特化を罰する。エリートは純粋な範囲ビルドを罰する。
- **鎖を尊重する。** 協力プレイではテザーは武器になる — 鎖でつながれた仲間を意図的に群衆に振り回そう。ただし広範囲のクリーブを持つボスの近くではやらないこと。
- **1ティアにつきボスを1体ずつ覚える。** アクト全体を覚え直そうとしないこと。自分を殺している遭遇戦を特定し、それを切り出して対策する。
- **コーデックスを使う。** ゲーム内コーデックスは敵、アフリクション、購入履歴を記録する。コミュニティメンバーは特定の項目の完成に問題があると報告しているので、実績チェックリストではなく参照ツールとして扱おう。

| 判断ポイント | 低ティア（1〜4） | 高ティア（7〜10） |
|---|---|---|
| パワーのためにレベルアップする？ | 通常ははい | アフリクションが生き延びられる場合のみ |
| 満タンまで回復する？ | はい | 緊急時以外はしばしばスキップ |
| ダメージかユーティリティか？ | ダメージ | ユーティリティ、機動力、群衆制御 |
| 戦うか位置を変えるか？ | 戦う | まず位置を変え、それからコミット |

## アフリクション、メタ進行、そして今後の展開

スタジオはロードマップについて異例なほどオープンだ。マルチプレイ実績やオフライン起動問題へのホットフィックスに加え、発表されている計画には、生のパワー稼ぎではなくコンテンツ解放とビルドカスタマイズに焦点を当てたメタ進行システムが含まれている — ゲームをスキルベースかつ協力プレイフレンドリーに保つことを明示的に狙った設計だ。名前付きアップデート（1.1）はローマを舞台にした新アリーナ、新ボス、新武器、対応する敵の追加を予定しており、PvPモードはさらに先の話として言及されている。

chained beasts難易度レベルに取り組んでいる人にとって、そのメタ進行は聞こえる以上に重要だ。解放とビルドの多様性が増えれば、現在は壁のように感じられるティアに対する有効な答えが増える。それはまさに高ティアが必要としているものだ。公式アナウンスやパッチノートは[Chained Beasts Steamコミュニティハブ](https://steamcommunity.com/app/3569420)で追える。開発陣がバランスアップデートやロードマップの詳細を直接投稿している。

それまでは、正直な期待値としてこう考えておこう。ソロで充実した10〜15時間、フルパーティならそれ以上を見込み、ティアは新しいアクトを渡すのではなく、同じ3アクトからリプレイバリューを絞り出すものだと期待しておくこと。それがこのゲームの取引であり、アフリクションの賭けを楽しむプレイヤーにとっては、良い取引なのだ。
